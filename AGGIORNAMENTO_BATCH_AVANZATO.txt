   • Seleziona Directory 2
   • ☑️ Genera Report HTML Unificato (già ON di default)

   • Click "📄 Apri Report HTML"
   • Usa i pulsanti per ordinare come vuoi!

💡 CASO D'USO: IDENTIFICAZIONE PERSONE

Scenario:
  Directory 1: 100 foto database persone
  Directory 2: 20 foto da identificare

Workflow nel report HTML:

1. ORDINA PER FILE 2 (Target):
   → Vedi tutte le comparazioni della foto1_target.jpg
   → I migliori match sono in cima per ogni foto

2. FILTRA SOLO ALTA:
   → Vedi solo match con ≥80% compatibilità
   → Identifica rapidamente le persone

3. CERCA SPECIFICA PERSONA:
   → Digita "mario" nella ricerca
   → Vedi solo comparazioni con "mario"
